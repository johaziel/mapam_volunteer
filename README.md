# GIT command

>add modification
git add .

> verification
git statut

> message pour le commit 
git commit -m "Undefined array key row_options"

> envoyer les modifs sur la branch main
git push -u origin main

> creer un tag (realease drupal)
git tag 1.0.4 THE.VERSION.NUMBER

> puis envoyer le tag 
git push origin 1.0.4
